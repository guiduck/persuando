# Lovable Prompt Base

Use this as the baseline for future prototype prompts after the first Spec Kit specification is created.

```text
Create a complete, navigable prototype for Persuando.

Persuando is a real-time contextual assistant with two modes:
1. Capture Mode, a Windows desktop app concept for settings, consent, tray/background status, and capture controls.
2. Response Mode, a web app concept for live transcript, incremental summary, insights, suggested responses, and session context.

Use the project documentation in docs/ as the product source of truth.
Use references/lovable-template/ as structure inspiration.
Use references/images/ as visual inspiration when provided.

The prototype must include:
- onboarding and sign-in entry points;
- user settings for provider keys, languages, capture options, consent, and retention;
- Capture Mode status and tray/background concepts;
- Response Mode session view with realistic meeting transcript, summary, insights, and suggestions;
- clear indicators for active capture and paused capture states;
- loading, empty, and error states;
- responsive desktop/tablet/mobile behavior for the Response App;
- accessible focus states and contrast;
- production-quality UI polish.

Do not build a generic landing page unless the request is specifically for a landing page.
Build the actual product workflow as the first screen.
Do not represent Persuando as invisible, undetectable, or as a tool for bypassing recording, screen sharing, browser focus detection, proctoring, or platform rules.
```
