# Vision

## Why This Exists

Important conversations and technical practice sessions move quickly. People often need to listen, think, take notes, remember context, and formulate useful responses at the same time. Persuando exists to reduce that cognitive load by turning authorized live context into transcripts, summaries, insights, and suggested next steps.

## Target Outcome

When Persuando works well, the user can:

- follow meetings with less stress;
- review what was said without reconstructing it from memory;
- receive concise suggestions, risks, objections, and questions in real time;
- receive plain-language explanations of concepts, keywords, and topics being discussed instead of only conversational filler;
- practice interviews and coding exercises with explanations in their preferred language;
- keep control over what is captured, processed, stored, and sent to AI providers.

## Principles

- Consent first: audio, transcription, screenshots, visual analysis, and provider usage require explicit user approval.
- User control: every sensitive mode can be paused, disabled, or revoked from settings or the tray.
- Minimal capture surface: the main Capture App should be able to disappear into the tray while a visible floating toolbar provides fast capture controls.
- Responsible use: the product supports productivity, preparation, coaching, and study; it must not be designed as a tool for bypassing interview, assessment, proctoring, browser, meeting, or recording rules.
- TypeScript-first delivery: prefer Electron, React, Next.js, and Node.js for the MVP so the first version can be built quickly without requiring Rust or C#.
- Prototype before production: use documentation and a navigable prototype to validate workflows before building the scalable application.
